# Why the film is a Monday-morning path

Written specs describe systems. Viewers remember runs.

The Grok Bridge spec is a job envelope, a 202, a callback, and a CRM session on someone else's computer. Drawn as architecture it is honest and useless: nobody watching can tell what Monday looks like.

The film that worked named a room (`#pipeline-review`), a person (Maya), an ask in spoken language, a second computer (Divyansh's Grok Bot), and an artifact (a five-row watch list). Everything else in the ADR was cut.

That cut is the skill. If a box in the diagram does not appear in the run, it does not get a Sequence.

## What agents default to

Coding agents, given "make a video of this spec," reach for:

1. Motion Canvas / Remotion boxes and arrows
2. A voiceover of the README
3. A video model of "AI agents collaborating"

All three fail the same way: they explain the diagram, not the product. `spec-video` exists so the default is the path instead.

## Complementary stack

Remotion is the wrong tool for a four-hour Screen Studio dump. FFmpeg (`video-editing`) cuts reality. fal.ai fills a hole (thumbnail, tick). Taste is last, in a real editor, if you are publishing.

The mistake is asking one of those tools to do the others' job — especially asking a video model to be the spec.
